Nothing changes in how Dapple works. This release picks up security fixes.

## What's changed

- **Updated system image.** Dapple now runs on the latest build of its base image, which carries the operating system's recent security patches.
- **An untrustworthy certificate authority removed.** One of Dapple's components ships a list of authorities it trusts for secure connections, and some of them were found to be compromised. Dapple only talks to your strands and your MQTT broker over your own network without encryption, so it never relied on that list, but the bad entries are gone now.
- **A security fix in the tools that build the web page.** It only affected a development preview server that never runs inside Dapple.

## Upgrading

Running Dapple as a Home Assistant app: install the update from Settings → Updates.

With Docker, `docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.6.4
```
