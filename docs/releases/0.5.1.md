Halloween gets a little yellow.

## What's changed

- **The built-in Halloween preset now has three colors:** a deeper orange (80%), purple (15%) and a touch of yellow (5%), where it used to be just orange and purple.

New installs start with the new Halloween. If you already run Dapple, your presets stay exactly as you left them, including Halloween. To get the new one, open Halloween in the pattern editor, add a yellow color, set the shares to 80, 15 and 5, and save it over the old one.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.5.1
```
