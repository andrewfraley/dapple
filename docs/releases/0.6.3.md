Nothing changes in Dapple itself. This release tightens how its building blocks are kept up to date.

## What's changed

- **A security fix in the tools that build the web page.** One of them could be made to hang by a deliberately broken file. It only runs while the image is being built, never inside Dapple, so it wasn't something your install was exposed to, but it's fixed all the same.
- **Fewer, more deliberate updates.** Dapple's building blocks are now updated automatically only when there's a security fix, rather than every week. The system image it runs on still gets its monthly security patches.

## Upgrading

Running Dapple as a Home Assistant app: install the update from Settings → Updates.

With Docker, `docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.6.3
```
