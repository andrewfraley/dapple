Nothing changes in Dapple itself. This release fixes how it gets built.

## What's changed

- **Builds no longer stall now and then.** Two copies of the image build could start at once for the same change and get in each other's way, which sometimes held up a release for many minutes. Now the second one waits its turn.

## Upgrading

Running Dapple as a Home Assistant app: install the update from Settings → Updates.

With Docker, `docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.6.2
```
