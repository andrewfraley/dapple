The pattern editor now starts on Halloween.

## What's changed

- **The editor's starting pattern is the built-in Halloween preset:** deeper orange (80%), purple (15%) and a touch of yellow (5%). It used to start on an older two-color orange and purple that didn't match any preset. You see it when a group has no pattern yet.

## Upgrading

Running Dapple as a Home Assistant app: install the update from Settings → Updates.

With Docker, `docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.6.1
```
