Dapple can now run inside Home Assistant, as an app.

## What's changed

- **Run Dapple on Home Assistant OS.** If your Home Assistant runs Home Assistant OS, you can install Dapple from Home Assistant's App store instead of setting up Docker on another computer. It opens in Home Assistant's sidebar, behind Home Assistant's login, and new versions arrive under Settings → Updates like any other app's. The README's [On Home Assistant OS](https://github.com/andrewfraley/dapple/blob/main/README.md#on-home-assistant-os) section has a one-click link to add it.
- **Less to type when connecting to Home Assistant.** Running as an app with the Mosquitto broker installed, Dapple fills in the broker's address and a login on its Home Assistant tab by itself. It still starts switched off: turn on **Connect to Home Assistant** and press **Save**.

Nothing changes if you run Dapple with Docker. To move an existing Docker install over to the app, add your strands again in the app (or copy `config.yaml` and `presets.json` across), then stop the Docker one so the two don't both control your lights.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.6.0
```
