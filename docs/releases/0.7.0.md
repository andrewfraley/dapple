Each group can now turn on and off by the clock.

## What's new

- **A daily schedule for each group.** On the Strands tab, the new clock button next to a group's name sets an on time, an off time, or both. The times are stored on the lights themselves, so they keep working with Dapple switched off. The time zone is filled in from your browser.

The same times apply every day, and the lights come on showing whatever the group last showed. For different times on different days, or a preset at a set time, use a Home Assistant automation. The README has the details under "Turning the lights on and off by the clock".

If you've set a timer in the Twinkly app, Dapple leaves it alone unless you give that group a schedule. Saving a schedule replaces it, and Dapple warns you first.

## Upgrading

Running Dapple as a Home Assistant app: install the update from Settings → Updates.

With Docker, `docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over, and nothing changes until you set a schedule. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.7.0
```
