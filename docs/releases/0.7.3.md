Your lights now get their brightness back after a power cut.

## What's changed

- **Brightness comes back after a power cut.** When lights lose power, they return with their pattern and schedule but at full brightness. Dapple now notices they restarted and sets them back to the brightness they were at, usually within a minute. It doesn't matter where you set that level: Dapple, Home Assistant and the Twinkly app all count. If Dapple was off too, it does this when it starts again.

Dapple checks the lights once a minute, so a change made less than a minute before the power went may not be the one that comes back. If you've already changed the brightness since the power came back, Dapple leaves your choice alone.

This starts with the next power cut after you upgrade. Lights already sitting at full brightness from an earlier one won't change, so set those once yourself.

## Upgrading

Running Dapple as a Home Assistant app: install the update from Settings → Updates.

With Docker, `docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.7.3
```
