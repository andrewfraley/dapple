Your lights now get their brightness back after a power cut.

## What's changed

- **Brightness comes back after a power cut.** When lights lose power, they return with their pattern and schedule but at full brightness. Dapple now notices they restarted and sets them back to the last brightness it sent, usually within a minute. If Dapple was off too, it does this when it starts again.

It only knows about brightness set through Dapple, including from Home Assistant through Dapple, so a level you set in the Twinkly app isn't what comes back. If you've already changed the brightness since the power came back, Dapple leaves your choice alone.

This starts with the next power cut after you upgrade. Lights already sitting at full brightness from an earlier one won't change, so set those once yourself.

## Upgrading

Running Dapple as a Home Assistant app: install the update from Settings → Updates.

With Docker, `docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.7.2
```
