Nothing changes in how Dapple works. This release picks up security fixes.

## What's changed

- **A security update to Tornado.** One of Dapple's components brings in this web library. Dapple doesn't use the parts of it these fixes cover, because Dapple's own web server is a different one, so you weren't exposed. The fixed version is in now, so it stays that way.
- **Security updates to the tools used to develop Dapple.** Black, filelock and virtualenv are only used while building and testing Dapple, and none of them are in the image you run.

## Upgrading

Running Dapple as a Home Assistant app: install the update from Settings → Updates.

With Docker, `docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.7.2
```
