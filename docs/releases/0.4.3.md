A maintenance release. Dapple works and looks exactly as before.

## What's changed

- **Updated build tools.** The tools that turn Dapple's web page into the files the app serves have been updated to their current versions, which fixes known security problems in the old ones. Those problems only affected developers building Dapple, not a running Dapple, but there's no reason to keep them.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.4.3
```
