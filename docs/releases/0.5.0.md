Dapple now shows which version you're running.

## What's new

- **The version number is at the bottom of every page**, with a link to Dapple on GitHub. If you ever report a problem, include that number. It comes from the running Dapple, so it's always the version you actually have.
- **Scripts can read the version too.** `http://<your-dapple>:8080/api/ping` now answers with it, for example `{"ok": true, "version": "0.5.0"}`.

Nothing else has changed, and there's nothing you need to do.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.5.0
```
