A maintenance release. Dapple itself is unchanged; this changes how its dependencies are kept up to date.

## What's changed

- **Updates wait a week before they're considered.** Dapple is checked every week for newer versions of the software it's built on, and a new version isn't taken until it's been out for 7 days. Most compromised packages are caught and pulled within that time. Fixes for known security problems still come straight away.
- **Big upgrades are done by hand.** Major new versions of the libraries Dapple uses, and new versions of Python or Node, are left for a person to make and test, not taken automatically. The Python and Node versions Dapple runs on still get their security fixes.

## Upgrading

`docker compose up -d` picks this up if you have `pull_policy: always`. Otherwise run `docker compose pull && docker compose up -d`. Your settings and saved presets carry over. To stay on this release, set the image line to:

```yaml
    image: afraley/dapple:0.4.2
```
